# 🔒 Secure Encryption Tool

A modern, privacy-focused client-side encryption tool with multiple encryption algorithms including AES-GCM, Base64 encoding, and Caesar cipher. Built with security and user experience in mind.

## 🌟 Features

- **🔐 Multiple Encryption Methods**
  - AES-GCM (Advanced Encryption Standard with Galois/Counter Mode)
  - Base64 Encoding/Decoding
  - Caesar Cipher (Educational purposes)

- **🛡️ Privacy First**
  - 100% client-side processing
  - No data transmission to servers
  - No tracking or analytics
  - All operations happen in your browser

- **✨ User Experience**
  - Clean, modern interface
  - Dark mode support with auto-detection
  - Password strength indicator
  - Real-time toast notifications
  - Responsive design for all devices
  - Keyboard shortcuts (Ctrl+Enter to encrypt)
  - Accessible (WCAG compliant)

- **⚡ Performance**
  - Fast encryption/decryption
  - Optimized for modern browsers
  - No external dependencies
  - Single HTML file deployment

## 🚀 Quick Start

1. Simply open `index.html` in any modern web browser
2. Select your preferred encryption algorithm
3. Enter your text and encryption key (for AES-GCM)
4. Click "Encrypt Data" or "Decrypt Data"
5. Copy the result to your clipboard

No installation or setup required!

## 🔧 Technical Details

### Encryption Algorithms

#### AES-GCM
- **Strength**: Military-grade encryption
- **Key Derivation**: PBKDF2 with 250,000 iterations
- **Hash**: SHA-256
- **Key Length**: 256-bit
- **Use Case**: Securing sensitive data

#### Base64
- **Type**: Encoding (not encryption)
- **Use Case**: Data transmission, encoding binary data

#### Caesar Cipher
- **Type**: Substitution cipher
- **Shift Range**: 1-25
- **Use Case**: Educational purposes only
